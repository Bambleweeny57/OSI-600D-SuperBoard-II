# Ohio Scientific 600 Rev D KiCad 9 verification pack

Generated using the syntax and unit naming demonstrated by the supplied working KiCad 9 ZX Spectrum Issue 4 schematic.

- U41 is represented as `27C16 CHARACTER GENERATOR`.
- U6, U7, U24 and U25 remain original 8T28 devices. No 74LS245 substitution is used.
- Component references and net names are carried from the supplied legacy sheets and supporting connection plans.
- Net labels are kept separate where the legacy generated files reused coordinates, avoiding false electrical joins. They are therefore verification cues until connected pin-by-pin against the scans.
- Embedded symbols are used so the files do not depend on a separate custom symbol library merely to open.

These are verification drawings, not fabrication-approved schematics.
